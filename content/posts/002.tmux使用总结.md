## 一、介绍

> tmux 是一个终端复用器：一个终端窗口里开多个面板，断开连接后程序继续跑，下次接回来一切还在。

三层结构，记住这三个词就够了：

| 层级 | 说明 |
| --- | --- |
| 会话 session | 一个项目一个会话，可分离、可重连 |
| 窗口 window | 相当于浏览器的标签页 |
| 面板 pane | 窗口里的分屏，可以左右或上下切 |

所有快捷键都要先按**前缀键**（默认 Ctrl+b），再按命令键。

## 二、安装

```bash
# fedora
sudo dnf install tmux

# Ubuntu/Debian
sudo apt-get install tmux

# CentOS/RHEL
sudo yum install tmux

# macOS (使用 Homebrew)
brew install tmux
```

## 三、配置

> 配置文件位于 ~/.tmux.conf，没有就自己建一个。

```bash
$ cat ~/.tmux.conf
# 启用鼠标支持（可以鼠标点击切换面板/窗口）
set -g mouse on

# 关闭备用屏幕（解决部分终端滚动异常）
# 注意：这会让 vim / less 退出后不留历史画面
set -g terminal-overrides 'xterm*:smcup@:rmcup@'

# 设置窗口从 1 开始编号（默认是 0）
set -g base-index 1
setw -g pane-base-index 1

# 确保终端支持 256 色
set -g default-terminal "screen-256color"
```

改完让配置生效：

```bash
tmux source-file ~/.tmux.conf
```

## 四、会话管理

| 命令 / 快捷键 | 说明 | 示例 |
| --- | --- | --- |
| tmux new | 创建新会话 | tmux new -s work |
| tmux ls | 列出所有会话 | tmux ls |
| tmux attach | 重新连接会话 | tmux a -t work |
| Ctrl+b d | 分离会话（后台继续跑） | 断网前先按这个 |
| Ctrl+b $ | 重命名当前会话 | 手速快的用，慢的直接改配置文件 |
| Ctrl+b s | 列出并切换会话 | 弹出列表，方向键选 |
| tmux kill-session | 杀死指定会话 | tmux kill-session -t work |
| tmux kill-server | 杀掉所有会话 | 相当于退出整个 tmux 服务 |

## 七、复制与粘贴

> tmux 会接手鼠标选中和滚轮，所以要记住这套机制。

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 进入复制模式 | Ctrl+b [ | 之后可用方向键 / PgUp 翻历史 |
| 标记起点 | 空格 | 复制模式下按空格开始选 |
| 复制 | 回车 | 存进 tmux 内部缓冲区 |
| 粘贴 | Ctrl+b ] | 从 tmux 缓冲区粘贴 |
| 搜索 | Ctrl+b [ 然后 ? 或 / | 向上 / 向下搜索 |
| 退出复制模式 | q | 按键没反应时先试这个 |
| 用终端自己的选择 | 按住 Shift 拖选 | 绕过 tmux，直接进系统剪贴板 |

想让 tmux 的复制直接进系统剪贴板，在配置里加一行（foot、kitty、wezterm、iTerm2 都支持）：

```bash
set -g set-clipboard on
```

## 八、面板同步输入

批量操作时极其省事：输一次，所有面板同时执行。

```
Ctrl+b 然后输入 :setw synchronize-panes on
```

关掉：

```
:setw synchronize-panes off
```

多台机器一起改配置、一起重启服务时，这个比开一堆 SSH 窗口快得多。

## 九、常用配置补充

```bash
# 滚动缓冲行数（默认只有 2000 行，编译日志一下就滚没了）
set -g history-limit 50000

# 关掉窗口后编号自动往前补，不留空号
set -g renumber-windows on

# 在面板边框上显示编号和标题
set -g pane-border-status top
set -g pane-border-format "#{pane_index}: #{pane_title}"

# 状态栏：左边当前会话，右边时间
set -g status-left "#[bold] #S "
set -g status-right "%m-%d %H:%M"
set -g status-interval 30
```

## 十、状态栏与命令模式

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 进入命令模式 | Ctrl+b : | 能做快捷键做不了的事 |
| 显示大时钟 | Ctrl+b t | 全屏时钟，等编译时用 |
| 显示当前会话信息 | Ctrl+b i | — |
| 列出所有快捷键 | Ctrl+b ? | 记不住时查这里 |

命令模式里一个实用例子，把面板输出录到文件：

```
:pipe-pane -o 'cat >> ~/tmux-$(date +%F).log'
```

## 十一、会话持久化

> tmux 只能保证进程不退出，机器重启就全没了。要断电恢复必须上插件。

| 插件 | 作用 |
| --- | --- |
| TPM | tmux 的插件管理器，装插件的前提 |
| tmux-resurrect | 手动保存 / 恢复会话布局和正在跑的程序 |
| tmux-continuum | 在 resurrect 之上自动定时保存、开机自动恢复 |

```bash
git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
```

在 ~/.tmux.conf 末尾加上：

```bash
set -g @plugin 'tmux-plugins/tpm'
set -g @plugin 'tmux-plugins/tmux-resurrect'
set -g @plugin 'tmux-plugins/tmux-continuum'

run '~/.tmux/plugins/tpm/tpm'
```

然后按 Ctrl+b I 安装插件。

不装插件也可以手动记布局：

```bash
tmux list-windows -F '#{window_name}: #{window_layout}'
```

把输出存下来，换机器后用 select-layout 还原。

## 十二、常见问题

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 关掉终端后程序被杀了 | 没在 tmux 里跑 | 先 tmux new -s work 再启动 |
| Ctrl+b 没反应 | 被终端或 shell 占用 | 改前缀键，或连按两次 Ctrl+b |
| 鼠标选中复制不到剪贴板 | tmux 接手了选择 | 按住 Shift 拖选，或开 set-clipboard |
| 看不到历史输出 | 已经滚到缓冲上限 | 调大 history-limit |
| 配置改了没生效 | 没重载 | tmux source-file ~/.tmux.conf |
| 按键没反应 | 误入复制模式 | 按 q 退出 |
| 嵌套 tmux 前缀键失灵 | 前缀键被外层 tmux 吃掉 | 连按两次 Ctrl+b，或配置 bind C-b send-prefix |

## 十三、一句话原则

**终端里跑的长任务一律放进 tmux。** 编译、下载、SSH、看日志——断网、关笔记本、SSH 掉线，回来 tmux attach 一切都还在。
