## 安装 tmux

```bash
# Fedora
sudo dnf install tmux

# Ubuntu / Debian
sudo apt-get install tmux

# CentOS / RHEL
sudo yum install tmux

# macOS（Homebrew）
brew install tmux
```

## 配置 tmux

> 配置文件位于 ~/.tmux.conf，没有就自己建一个。

```bash
cat ~/.tmux.conf

# 启用鼠标支持（可以鼠标点击切换面板 / 窗口）
set -g mouse on

# 关闭备用屏幕（解决部分终端里滚动异常的问题）
# 注意：这会让 vim / less 之类的全屏程序退出后不留历史画面
set -g terminal-overrides 'xterm*:smcup@:rmcup@'

# 窗口编号从 1 开始（默认是 0）
set -g base-index 1
setw -g pane-base-index 1

# 确保终端支持 256 色
set -g default-terminal "screen-256color"
```

改完让配置生效：

```bash
tmux source-file ~/.tmux.conf
```

## 常用命令与快捷键

tmux 的所有操作都要先按**前缀键**（默认 Ctrl+b），再按命令键。

### 会话管理

| 命令 / 快捷键 | 说明 |
| --- | --- |
| tmux new -s 名字 | 创建名为该名字的新会话 |
| Ctrl+b d | 分离当前会话（会话在后台继续运行） |
| tmux ls | 列出所有会话 |
| tmux a -t 名字 | 重新连接到指定会话（attach 同义） |
| Ctrl+b $ | 重命名当前会话 |
| Ctrl+b s | 切换会话 |
| tmux kill-session -t 名字 | 杀死指定会话 |
| tmux kill-server | 杀掉所有会话（退出 tmux 服务） |

### 窗口管理

| 命令 / 快捷键 | 说明 |
| --- | --- |
| Ctrl+b c | 创建新窗口 |
| Ctrl+b & | 关闭当前窗口 |
| Ctrl+b n | 切换到下一个窗口 |
| Ctrl+b p | 切换到上一个窗口 |
| Ctrl+b 数字 | 切换到指定编号的窗口 |
| Ctrl+b , | 重命名当前窗口 |
| Ctrl+b w | 列出所有窗口并选择 |
| Ctrl+b f | 在所有窗口中搜索内容 |

### 面板管理

| 命令 / 快捷键 | 说明 |
| --- | --- |
| Ctrl+b % | 垂直分割当前面板（左右并排） |
| Ctrl+b " | 水平分割当前面板（上下堆叠） |
| Ctrl+b 方向键 | 在面板间移动焦点 |
| Ctrl+b o | 按顺序切到下一个面板 |
| Ctrl+b q | 显示面板编号，按数字直接跳过去 |
| Ctrl+b x | 关闭当前面板 |
| Ctrl+b z | 最大化 / 恢复当前面板 |
| Ctrl+b Space | 切换面板布局 |
| Ctrl+b { 或 } | 把当前面板向前 / 向后移动位置 |
| Ctrl+b 然后 Ctrl+= / Ctrl+- | 调整面板大小（先按前缀键，再按组合键） |

## 复制与粘贴

tmux 里的鼠标选中、滚轮滚动都会被它自己接管，用之前要先知道这套机制。

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 进入复制模式 | Ctrl+b [ | 之后可以用方向键 / PgUp 滚动历史 |
| 开始选择 | 空格 | 复制模式下按空格标记起点 |
| 复制选中内容 | 回车 | tmux 内部缓冲区 |
| 粘贴 | Ctrl+b ] | 从 tmux 缓冲区粘贴 |
| 搜索 | Ctrl+b [ 然后 ? 或 / | 向上 / 向下搜索 |
| 退出复制模式 | q | 回到正常模式 |
| 用终端自己的选择 | 按住 Shift 拖选 | 绕过 tmux，直接复制到系统剪贴板 |

> 觉得 tmux 的复制太麻烦，可以让它走系统剪贴板：
>
> ```
> set -g set-clipboard on
> ```
>
> 配合终端支持（foot、kitty、wezterm、iTerm2 都支持）就能直接写进系统剪贴板。

## 面板同步输入

这个功能很多人不知道，但批量操作时极其省事：

```
Ctrl+b 然后输入 :setw synchronize-panes on
```

输一次，所有面板同时执行。多台机器一起改配置、一起重启服务时非常好用。

关掉：

```
:setw synchronize-panes off
```

## 常用配置补充

```bash
# 滚动缓冲行数（默认只有 2000 行，跑编译日志会不够）
set -g history-limit 50000

# 关掉窗口后编号自动往前补，不留空号
set -g renumber-windows on

# 在面板边框上显示编号和标题
set -g pane-border-status top
set -g pane-border-format "#{pane_index}: #{pane_title}"

# 状态栏：左边当前会话，右边时间
set -g status-left "#[bold] #S "
set -g status-right "%m-%d %H:%M"
set -g status-interval 30
```

## 状态栏与命令行

| 操作 | 快捷键 |
| --- | --- |
| 进入命令模式 | Ctrl+b : |
| 显示大时钟 | Ctrl+b t |
| 显示当前会话信息 | Ctrl+b i |
| 列出所有快捷键绑定 | Ctrl+b ? |

命令模式里能做的事很多，比如把某个面板的输出记录到文件：

```
:pipe-pane -o 'cat >> ~/tmux-$(date +%F).log'
```

## 会话持久化

tmux 自己只能保证**进程不退出**，机器重启就没了。真要做到断电恢复，需要插件：

| 插件 | 作用 |
| --- | --- |
| TPM | tmux 的插件管理器，装插件的前提 |
| tmux-resurrect | 手动保存 / 恢复整个会话布局和程序 |
| tmux-continuum | 在 resurrect 之上自动定时保存、开机自动恢复 |

安装方式（TPM）：

```bash
git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
```

在 ~/.tmux.conf 末尾加上：

```bash
set -g @plugin 'tmux-plugins/tpm'
set -g @plugin 'tmux-plugins/tmux-resurrect'
set -g @plugin 'tmux-plugins/tmux-continuum'

run '~/.tmux/plugins/tpm/tpm'
```

然后 Ctrl+b I 安装插件。

不想装插件的话，也可以手动记下当前布局：

```bash
tmux list-windows -F '#{window_name}: #{window_layout}'
```

把输出存下来，重装或换机器后用 `select-layout` 还原。

## 几个常见问题

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 关掉终端后程序被杀了 | 没在 tmux 里跑 | 先 tmux new -s work 再启动 |
| Ctrl+b 没反应 | 被终端或 shell 占用 | 改前缀键，或连按两次 Ctrl+b |
| 鼠标选中复制不到系统剪贴板 | tmux 接管了选择 | 按住 Shift 拖选，或开 set-clipboard |
| 滚动条看不到历史 | 已经滚到缓冲上限 | 调大 history-limit |
| 配置改了没生效 | 没重载 | tmux source-file ~/.tmux.conf |
| 误入复制模式，按键没反应 | 在复制模式里 | 按 q 退出 |
| 嵌套 tmux 时前缀键失灵 | 前缀键被内层吃掉了 | 连按两次 Ctrl+b，或配置 bind C-b send-prefix |

## 一句话原则

终端里跑的长任务（编译、下载、SSH、日志）一律放进 tmux。断网、关笔记本、SSH 掉线，回来 tmux attach 一切都还在。
