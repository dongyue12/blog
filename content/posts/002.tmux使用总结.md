## 安装 tmux

```bash
# Fedora
sudo dnf install tmux

# Ubuntu / Debian
sudo apt-get install tmux

# CentOS / RHEL
sudo yum install tmux

# macOS（Homebrew）
brew install tmux
```

## 配置 tmux

> 配置文件位于 `~/.tmux.conf`，没有就自己建一个。

```bash
cat ~/.tmux.conf

# 启用鼠标支持（可以鼠标点击切换面板 / 窗口）
set -g mouse on

# 关闭备用屏幕（解决部分终端里滚动异常的问题）
# 注意：这会让 vim / less 之类的全屏程序不留历史画面
set -g terminal-overrides 'xterm*:smcup@:rmcup@'

# 窗口编号从 1 开始（默认是 0）
set -g base-index 1
setw -g pane-base-index 1

# 确保终端支持 256 色
set -g default-terminal "screen-256color"
```

改完让配置生效：

```bash
tmux source-file ~/.tmux.conf
```

## 常用命令与快捷键

tmux 的所有操作都要先按**前缀键**（默认 `Ctrl+b`），再按命令键。

### 会话管理

| 命令 / 快捷键 | 说明 |
| --- | --- |
| `tmux new -s <name>` | 创建名为 name 的新会话 |
| `Ctrl+b d` | 分离当前会话（会话在后台继续运行） |
| `tmux ls` | 列出所有会话 |
| `tmux a -t <name>` | 重新连接到指定会话（`attach` 同义） |
| `Ctrl+b $` | 重命名当前会话 |
| `Ctrl+b s` | 切换会话 |
| `tmux kill-session -t <name>` | 杀死指定会话 |

### 窗口管理

| 命令 / 快捷键 | 说明 |
| --- | --- |
| `Ctrl+b c` | 创建新窗口 |
| `Ctrl+b &` | 关闭当前窗口 |
| `Ctrl+b n` | 切换到下一个窗口 |
| `Ctrl+b p` | 切换到上一个窗口 |
| `Ctrl+b <number>` | 切换到指定编号的窗口 |
| `Ctrl+b ,` | 重命名当前窗口 |
| `Ctrl+b w` | 列出所有窗口并选择 |

### 面板管理

| 命令 / 快捷键 | 说明 |
| --- | --- |
| `Ctrl+b %` | 垂直分割当前面板（左右并排） |
| `Ctrl+b "` | 水平分割当前面板（上下堆叠） |
| `Ctrl+b <arrow>` | 在面板间移动焦点 |
| `Ctrl+b o` | 按顺序切到下一个面板 |
| `Ctrl+b x` | 关闭当前面板 |
| `Ctrl+b z` | 最大化 / 恢复当前面板 |
| `Ctrl+b Space` | 切换面板布局 |
| `Ctrl+b` 然后 `Ctrl+=` / `Ctrl+-` | 调整面板大小（先按前缀键，再按组合键） |
