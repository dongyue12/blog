## 安装tmux

```bash
# fedora
sudo dnf install tmux

# Ubuntu/Debian
sudo apt-get install tmux

# CentOS/RHEL
sudo yum install tmux

# macOS (使用 Homebrew)
brew install tmux
```

## 配置tmux

> tmux 的配置文件位于 ~/.config/tmux/tmux.conf。以下是一些常用配置示例：

```bash
# ---------- 基础 ----------
set -g mouse on                          # 鼠标选中、切面板、拖边框
set -g base-index 1                      # 窗口编号从 1 开始
setw -g pane-base-index 1                # 面板编号从 1 开始
set -g renumber-windows on               # 关掉窗口后编号自动补位，不留空号

# ---------- 终端 ----------
set -g default-terminal "tmux-256color"  # screen-256color 会丢真彩色
set -ga terminal-features ",foot*:RGB"   # 明确告诉 tmux：foot 支持 RGB
set -sg escape-time 0                    # ESC 不再等 10ms，vim/nvim 手感明显变快

# ---------- 缓冲与剪贴板 ----------
set -g history-limit 50000               # 默认只有 2000 行，看日志不够
set -g set-clipboard on                  # 允许程序（如 nvim）通过 OSC52 写系统剪贴板
set -g focus-events on                   # 切回终端时通知应用（配合 nvim 自动重载）

# ---------- 复制模式（vi 键位）----------
# emacs 键表里 Space 是"向下翻页"，vi 键表里 Space 才是"开始选择"
setw -g mode-keys vi
bind -T copy-mode-vi v send -X begin-selection          # 复制v
bind -T copy-mode-vi y send -X copy-pipe-and-cancel     # 粘贴 y

# ---------- 状态栏（保持最简）----------
set -g status-left " #S "
set -g status-right "%H:%M "
set -g status-interval 10

```
输入`tmux source-file ~/.config/tmux/tmux.conf`就可以重新加载tmux

### 命令管理

常用命令与快捷键

tmux 的所有操作都需要先按下前缀键（默认是 Ctrl+b），然后输入命令键。

#### 会话管理

| 命令/快捷键 | 说明 |
| --- | --- |
| tmux new -s <name> | 创建名为 name 的新会话 |
| Ctrl+b d | 分离当前会话（会话继续后台运行） |
| tmux ls | 列出所有会话 |
| tmux a/attach -t <name> | 重新连接到指定会话 |
| Ctrl+b $ | 重命名当前会话 |
| Ctrl+b s | 切换会话 |
| tmux kill-session -t 0 | 杀死会话 |
| tmux kill-session -t <name> | 杀死会话 |

#### 窗口管理

| 命令/快捷键 | 说明 |
| --- | --- |
| Ctrl+b c | 创建新窗口 |
| Ctrl+b & | 关闭当前窗口 |
| Ctrl+b n | 切换到下一个窗口 |
| Ctrl+b p | 切换到上一个窗口 |
| Ctrl+b <number> | 切换到指定编号的窗口 |
| Ctrl+b , | 重命名当前窗口 |

#### 面板管理

| 命令/快捷键 | 说明 |
| --- | --- |
| Ctrl+b % | 垂直分割当前面板 |
| Ctrl+b " | 水平分割当前面板 |
| Ctrl+b <arrow> | 在面板间移动焦点 |
| Ctrl+b x | 关闭当前面板 |
| Ctrl+b z | 最大化/恢复当前面板 |
| Ctrl+b Space | 切换面板布局 |
| Ctrl+b-ctrl+=/- | 切换窗口大小，先按Ctrl+b触发在Ctrl+=/-切换大小 |

#### 复制和粘贴
tmux里空格是开始复制，但是会和终端的快捷键冲突，导致直接翻页跳转到底部，很难后，所以我改为来vi快捷键

| 命令/快捷键 | 说明 |
|---|---|
| Ctrl+b [          | 进入复制模式   |
| 移动光标+v        | 开始复制       |
| 按y               | 复制并结束     |
