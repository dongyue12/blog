## 安装tmux

```bash
# fedora
sudo dnf install tmux

# Ubuntu/Debian
sudo apt-get install tmux

# CentOS/RHEL
sudo yum install tmux

# macOS (使用 Homebrew)
brew install tmux
```

## 配置tmux

> tmux 的配置文件位于 ~/.tmux.conf。以下是一些常用配置示例：

```bash
$ cat tmux.conf
# 启用鼠标支持（可以鼠标点击切换面板/窗口）
set -g mouse on
# 鼠标滚动
set -g terminal-overrides 'xterm*:smcup@:rmcup@'

# 设置窗口从1开始编号（默认是0）
set -g base-index 1
setw -g pane-base-index 1

# 确保终端支持 256 色
set -g default-terminal "screen-256color"
```

### 命令管理

常用命令与快捷键

tmux 的所有操作都需要先按下前缀键（默认是 Ctrl+b），然后输入命令键。

#### 会话管理

| 命令/快捷键 | 说明 |
| --- | --- |
| tmux new -s <name> | 创建名为 name 的新会话 |
| Ctrl+b d | 分离当前会话（会话继续后台运行） |
| tmux ls | 列出所有会话 |
| tmux a/attach -t <name> | 重新连接到指定会话 |
| Ctrl+b $ | 重命名当前会话 |
| Ctrl+b s | 切换会话 |
| tmux kill-session -t 0 | 杀死会话 |
| tmux kill-session -t <name> | 杀死会话 |

#### 窗口管理

| 命令/快捷键 | 说明 |
| --- | --- |
| Ctrl+b c | 创建新窗口 |
| Ctrl+b & | 关闭当前窗口 |
| Ctrl+b n | 切换到下一个窗口 |
| Ctrl+b p | 切换到上一个窗口 |
| Ctrl+b <number> | 切换到指定编号的窗口 |
| Ctrl+b , | 重命名当前窗口 |

#### 面板管理

| 命令/快捷键 | 说明 |
| --- | --- |
| Ctrl+b % | 垂直分割当前面板 |
| Ctrl+b " | 水平分割当前面板 |
| Ctrl+b <arrow> | 在面板间移动焦点 |
| Ctrl+b x | 关闭当前面板 |
| Ctrl+b z | 最大化/恢复当前面板 |
| Ctrl+b Space | 切换面板布局 |
| Ctrl+b-ctrl+=/- | 切换窗口大小，先按Ctrl+b触发在Ctrl+=/-切换大小 |
| Ctrl+b o | 按顺序切到下一个面板（两个面板时最省事） |
| Ctrl+b q | 显示面板编号，按数字直接跳过去 |
| Ctrl+b { 或 } | 把当前面板向前 / 向后移动位置 |

## 复制与粘贴

> tmux 会接手鼠标选中和滚轮，所以要单独记这一套机制。

| 命令/快捷键 | 说明 |
| --- | --- |
| Ctrl+b [ | 进入复制模式，之后用方向键或 PgUp 翻历史 |
| 空格 | 复制模式下标记选中起点 |
| 回车 | 复制选中的内容到 tmux 缓冲区 |
| Ctrl+b ] | 从 tmux 缓冲区粘贴 |
| Ctrl+b [ 然后 ? 或 / | 在历史里向上 / 向下搜索 |
| q | 退出复制模式（按键没反应时先试这个） |
| 按住 Shift 拖选 | 绕过 tmux，直接用终端自己的选择复制到系统剪贴板 |

让 tmux 的复制直接写进系统剪贴板（foot、kitty、wezterm、iTerm2 都支持）：

```bash
$ cat ~/.tmux.conf
set -g set-clipboard on
```

## 同步输入

> 一个窗口里的多个面板同时执行相同命令，批量操作时用。

```
Ctrl+b 然后输入 :setw synchronize-panes on
```

关掉：

```
:setw synchronize-panes off
```

多台机器一起改配置、一起重启服务时，比开一堆 SSH 窗口快得多。

## 常用配置补充

```bash
$ cat ~/.tmux.conf
# 滚动缓冲行数（默认只有 2000 行，编译日志一下就滚没了）
set -g history-limit 50000

# 关掉窗口后编号自动往前补，不留空号
set -g renumber-windows on

# 在面板边框上显示编号和标题
set -g pane-border-status top
set -g pane-border-format "#{pane_index}: #{pane_title}"

# 状态栏：左边当前会话，右边时间
set -g status-left "#[bold] #S "
set -g status-right "%m-%d %H:%M"
set -g status-interval 30
```

## 状态栏与命令模式

| 命令/快捷键 | 说明 |
| --- | --- |
| Ctrl+b : | 进入命令模式，能做快捷键做不了的事 |
| Ctrl+b t | 显示大时钟 |
| Ctrl+b i | 显示当前会话信息 |
| Ctrl+b ? | 列出所有快捷键绑定 |

命令模式里一个实用例子，把面板输出录到文件：

```
:pipe-pane -o 'cat >> ~/tmux-$(date +%F).log'
```

## 会话持久化

> tmux 只能保证进程不退出，机器重启就全没了。要断电恢复必须上插件。

| 插件 | 说明 |
| --- | --- |
| TPM | tmux 的插件管理器，装插件的前提 |
| tmux-resurrect | 手动保存 / 恢复会话布局和正在跑的程序 |
| tmux-continuum | 在 resurrect 之上自动定时保存、开机自动恢复 |

```bash
$ git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
```

```bash
$ cat ~/.tmux.conf
set -g @plugin 'tmux-plugins/tpm'
set -g @plugin 'tmux-plugins/tmux-resurrect'
set -g @plugin 'tmux-plugins/tmux-continuum'

run '~/.tmux/plugins/tpm/tpm'
```

装完按 Ctrl+b I 安装插件。

不装插件也可以手动记下当前布局，换机器后用 select-layout 还原：

```bash
$ tmux list-windows -F '#{window_name}: #{window_layout}'
```

## 常见问题

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 关掉终端后程序被杀了 | 没在 tmux 里跑 | 先 tmux new -s work 再启动 |
| Ctrl+b 没反应 | 被终端或 shell 占用 | 改前缀键，或连按两次 Ctrl+b |
| 鼠标选中复制不到剪贴板 | tmux 接手了选择 | 按住 Shift 拖选，或开 set-clipboard |
| 看不到历史输出 | 已经滚到缓冲上限 | 调大 history-limit |
| 配置改了没生效 | 没重载 | tmux source-file ~/.tmux.conf |
| 按键没反应 | 误入复制模式 | 按 q 退出 |
| 嵌套 tmux 前缀键失灵 | 被外层 tmux 吃掉 | 连按两次 Ctrl+b，或配置 bind C-b send-prefix |
