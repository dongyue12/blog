### 标题

用 `#` 表示层级，一级最大，最多六级：

````markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
````

### 列表

无序列表用 `-`（`*`、`+` 也可以），有序列表用 `1.`，缩进两格（或四个空格）表示嵌套：

````markdown
- 第一项
- 第二项
  - 嵌套一项
    1. 再嵌一层

1. 第一步
2. 第二步
3. 第三步
````

任务列表（Obsidian、GitHub 支持；本博客的渲染器不认，会显示成普通列表）：

````markdown
- [ ] 待办
- [x] 已完成
````

### 链接

链接、锚点、图片是同一个套路：`[文字](地址)`、`[文字](#锚点)`、`![说明](图片地址)`。

````markdown
[百度](https://www.baidu.com)
[跳到本文的「表格」一节](#表格)
![图片说明](https://example.com/a.png)
````

博客文章里的图片放在 `public/img/` 下，正文写 `/img/文件名.webp` 即可。

### 代码块

一行的用一对反引号包起来，整段的用三个反引号，并在后面写上语言名（有语法高亮）：

````markdown
行内这样写：`const a = 1`。

```js
const a = 1;
console.log(a);
```
````

### 引用

行首写 `>`，多写几个就是嵌套：

> 引用一段话。
> > 再嵌一层。

````markdown
> 引用一段话。
>
> > 再嵌一层。
````

引用里也可以放链接和列表，和普通正文一样写。

### 表格

三行起：表头、分隔行、内容行。竖线 `|` 分列：

````markdown
| 表头 1 | 表头 2 | 表头 3 |
| --- | --- | --- |
| 内容 1 | 内容 2 | 内容 3 |
| 内容 1 | 内容 2 | 内容 3 |
````

在分隔行加冒号可以控制对齐：

- `:---` 左对齐（默认）
- `:---:` 居中
- `---:` 右对齐

````markdown
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| A | B | C |
````

效果：

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| A | B | C |

### 文字样式

| 效果 | 写法 |
| --- | --- |
| **加粗** | `**加粗**` |
| *斜体* | `*斜体*` |
| ~~删除线~~ | `~~删除线~~` |
| 行内代码 | 一对反引号包住，如 `` `code` `` |

Obsidian / Typora 还有几个扩展写法：

| 效果 | 写法 |
| --- | --- |
| 高亮 | `==高亮==` |
| 上标 | `X^2^` |
| 下标 | `H~2~O` |
| 下划线 | `<u>下划线</u>` |
