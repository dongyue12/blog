### 为什么选择 Rust

Rust 是一门系统编程语言，主打安全、并发和性能。

### 所有权系统

```rust
fn main() {
    let s = String::from("hello");
    let s2 = s.clone();
    println!("{}", s);
}
```

### 生命周期

生命周期注解是 Rust 中独特的语法，用于保证引用的有效性。

### 错误处理

Rust 使用 `Result<T, E>` 和 `Option<T>` 来处理可恢复错误，使用 `panic!` 处理不可恢复错误。

> 学习 Rust 需要转变思维方式，但一旦掌握，你会爱上它的安全性。
