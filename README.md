# 冬月的博客

用 Node.js 从零手写的静态博客：Markdown 进，纯静态 HTML 出。

## 技术栈

| 部分 | 用什么 |
|---|---|
| 运行时 | Node.js 22（ESM，`.mjs`） |
| 依赖 | 仅 3 个：`gray-matter`（拆 frontmatter）、`markdown-it`（Markdown → HTML）、`highlight.js`（构建时代码高亮） |
| 模板 | 原生 JS 模板字符串，无模板引擎 |
| 样式 | 原生 CSS，构建时压缩并内联进页面 |
| 前端脚本 | 原生 JS 内联，无框架；评论用 Giscus（GitHub Discussions） |
| 构建 | 自己写的 `src/build.mjs`，无打包器 |
| 产物 | `dist/` 纯静态文件，零后端 |

## 命令

```bash
npm run dev      # 预览开发：改文件自动重建 + 浏览器自动刷新 → http://localhost:8000
npm run build    # 构建，产物写入 dist/
npm run serve    # 只服务 dist/（不重建、不注入开发脚本）
npm run size     # 查看体积报告，超出预算会返回退出码 1
```

首次使用先装依赖：

```bash
npm install
```

## 写一篇文章

在 `content/posts/` 建文件，文件名格式 `3位编号.标题.md`，编号取当前最大值 + 1：

```markdown
---
date: 2026-05-01
tags: [随笔]
---

正文用 Markdown 写。图片放 `public/img/`，这里写 `/img/文件名.webp`。
```

- 编号即 URL：`012.标题.md` → `/posts/012/`，**不复用、不重排**
- `date:` 冒号后必须有空格
- 标题里不能有 `/ : * ? " < > |`

代码块写上语言名就会高亮（构建时染好颜色，前端不带任何高亮脚本）：

````markdown
```js
console.log('hello')
```
````

支持 `js` / `javascript` / `css` / `html`（`xml`）/ `bash`（`sh`）/ `json` / `md`（`markdown`）；
其它语言或没写语言名就按纯文本渲染。想加新语言，在 `src/highlight.mjs` 里注册一个就行。
配色在 `src/style.css` 的 `--code-*` 变量里，浅色/深色各一套。

## 写一篇文档

`content/document/` 是长期笔记，**一个文件夹 = 一个分类**，文件夹里还能再套文件夹：

```
content/document/前端/002.CSS/001.css是什么.md
        └ 分类 ┘  └ 子目录 ┘  └ 文档 ┘
```

对应的地址是 `/docs/前端/002.CSS/001.css是什么/`（路径就取自磁盘上的文件夹和文件名）。
文件名统一用 **3 位编号**开头（`001.` `002.` …），文件夹也一样。

文档不需要 frontmatter，直接写 Markdown 就行：

```markdown
# 1.css是什么

## CSS 简介

正文……
```

- 标题取正文第一行的一级标题；没有就用文件名（自动去掉 `001.` 这种编号前缀）
- 想覆盖标题或给搜索引擎一句摘要，可以加 frontmatter：`title:` / `description:`
- 以 `.` 或 `_` 开头的文件/文件夹会被忽略（`.excalidraw.md` 也会自动跳过），想临时藏一篇就改个名
- 在文件夹里放一个 `_index.md`，正文会作为分类页的介绍（可写「先读这里」）
- 图片同样放 `public/img/`，写 `/img/文件名.webp`（文档里的相对路径图片不会被打包）

### 用数字决定顺序

**文件夹和文件名的编号前缀 = 排序键**，数字多大就排多后，不看字母：

```
content/document/前端/
  001.HTML/          → 1
  002.CSS/           → 2
  003.JavaScript/    → 3
  004.Mermaid/       → 4
  005.Vue/           → 5
```

文件夹内部的文档同理，按编号正序就是「上一篇 / 下一篇」的顺序：

```
002.CSS/
  001.css是什么.md       → 1
  002.链接外部css.md     → 2
  ...
  009.CSS字体.md         → 9
  010.CSS颜色.md         → 10（按数字比，不按字符串比）
  015.CSS动画.md         → 15
```

规则：

| 写法 | 认不认 | 说明 |
|---|---|---|
| `1.` `01.` `001.` `0003.` | ✅ | 位数随意，按数值比较 |
| `1_` `1-` `1、` `1 `（空格） | ✅ | 分隔符换成别的也行 |
| `Markdown语法.md` | ✅ | 没编号的排在所有编号之后，彼此按名字排 |
| `第1章.md` | ❌ | 数字必须在开头 |

- 编号只用来排序：**标题不会带编号**（一级标题和文件名完全相同时，自动用去掉编号的名字）
- 但 URL 会保留编号（`/docs/前端/002.CSS/010.CSS颜色/`），这样地址和磁盘上的文件名能对上，也不会因为改标题而断链
- 想手动控制位置：换个编号就行，不用改动其它文件

页面结构：

| 地址 | 内容 |
|---|---|
| `/docs/` | 全部分类 + 每类的文章数 |
| `/docs/前端/` | **直接就是这一类的第一篇**（点分类就开始读，左侧栏里有完整目录） |
| `/docs/前端/002.CSS/001.css是什么/` | 单篇文档：左侧整类目录、顶部面包屑、右侧本页目录（窗口 ≥1150px 时）、上下篇 |
